EVENTIFY - EXACT WIREFRAME FRONTEND
==================================

Open index.html to start.

Technology:
- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5.3

Pages:
1. index.html
2. explore.html
3. event-details.html
4. checkout.html
5. login.html
6. signup.html
7. dashboard.html
8. about.html
9. contact.html

Validation included:
- Required fields
- Email format and length
- Name format and length
- Password minimum/maximum length
- Terms acceptance on signup and checkout
- Billing address validation
- ZIP code validation
- Payment method switching (card / PayPal)
- Card number Luhn validation
- Expiry month/year + future-date validation
- CVV validation
- Contact subject/message length validation
- Newsletter email validation
- Live validation + Bootstrap invalid/valid states

Functionality:
- Event search/filter/sort
- Event detail pages
- Ticket quantity limits
- Dynamic booking totals
- Wishlist demo
- Checkout demo
- Login/signup demo using localStorage
- Dashboard demo booking state
- FAQ accordion
- Responsive Bootstrap layout
- Event and team photos via image URLs

IMPORTANT:
This is a frontend-only project. Client-side validation is implemented thoroughly, but true server-side validation, authentication, database storage, payment processing, and security cannot be guaranteed by HTML/CSS/JavaScript alone. Never use this demo for real payment processing without a secure backend/payment provider.
